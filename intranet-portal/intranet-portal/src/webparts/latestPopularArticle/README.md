# LatestPopularArticle WebPart

## Purpose
This webpart displays the latest and popular articles from the intranet. It supports multiple layout styles including List, Row, and Carousel.

## Recent Changes
- Refactored component to support three layouts: List, Row, and Carousel.
- Implemented state-based internal carousel logic independent of external libraries like Swiper.
- Styled with modern MUI-inspired UI (e.g. rounded cards, hover effects, blue circular nav buttons).
- Fixed issues with missing `hideUIFilter` property references.
